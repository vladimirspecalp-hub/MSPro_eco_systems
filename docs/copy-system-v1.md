### Слабые места CTR/конверсии

1. **Hero-блок на главной**: Заголовок "Промышленные услуги высотных работ и защитных покрытий" — слишком общий, не цепляет боль клиента
2. **Отсутствие value proposition**: Нет чёткого "почему мы" в первом экране
3. **CTA-кнопки везде одинаковые**: "Рассчитать стоимость" не адаптируется под intent
4. **Формы без микрокопирайтинга**: Нет подсказок "что дальше", нет снятия страха
5. **FAQ шаблонный**: Одни и те же 3 вопроса на всех 2449 страницах
6. **Блок доверия отсутствует**: Нет документов/лицензий/СРО на видном месте
7. **GEO не персонализирован**: "Москва и область" везде, даже для СПб-страниц
8. **Нет Answer Block для AEO**: Поисковики не могут выдернуть прямой ответ
9. **title/description шаблонные**: Низкий CTR в поиске
10. **Нет единой ответственности**: Не закрыта боль "материал vs подрядчик"

## D) GEO-ПРАВИЛА

### Принципы локализации

1. Не выдумывать офисы/филиалы — только "выездные бригады"
2. Менять {city} и {region} в H1/офферах
3. Добавлять "работаем в {city}" в CTA
4. Не указывать адреса, если их нет

### Примеры локализаций

**Москва:**
- H1: Огнезащита металлоконструкций в Москве — MSPRO
- Оффер: Выезд инженера по Москве и области бесплатно

**Санкт-Петербург:**
- H1: Антикоррозионная защита в СПб — бригады с опытом
- Оффер: Работаем по СПб и Ленобласти. Материалы на складе.

**По РФ:**
- H1: {service} по всей России — выездные бригады
- Оффер: Мобильные бригады в любом регионе. Логистика материалов включена.
